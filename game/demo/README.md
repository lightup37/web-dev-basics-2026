# 拿破仑战争 · 回合制策略小游戏

> 小学期小组项目 · 纯前端（HTML + CSS + JavaScript）实现的静态网页小游戏

---

## 1. 项目是什么？

一款**回合制策略小游戏**：在 10×10 棋盘上指挥拿破仑的蓝色军团，在限定回合内消灭所有红色敌军即可过关。玩家每回合为友方棋子设定移动目标，棋子会自动前进并攻击进入射程的敌人。

- 共 **7 关**（6 个主线关卡 + 1 个隐藏关），另有失败 / 正常 / 隐藏三种结局；
- 包含账号、多存档、成就、剧情对话、敌方 AI 等完整单机体验。

## 2. 项目来源与背景

以**拿破仑战争**为背景的小学期小组作业，目标是做一个“简单但有正反馈的策略小游戏”：

- **失败结局**：拿破仑提早失利（`fail.html`）；隐藏第 7 关败北另有“命运无法改变”结局（`destiny-fail.html`）。
- **正常结局**：同正史走向——胜战后暗示多年后的滑铁卢（`end-game.html`）。
- **隐藏结局**：拿破仑统治欧洲（`hidden-end.html`）。解锁方式：第 1 关在 **12 回合内**通关开启隐藏路线，通关第 6 关后进入高难第 7 关，再胜即见隐藏结局。

设计理念：红方每个关卡的 AI 固定可复现，鼓励玩家**摸清敌方策略后针对性破解**。

## 3. 项目的具体内容

```text
拿破仑战争（纯静态网页）
├── 账号系统      注册/登录（localStorage，无需安全）、小组介绍页
├── 主界面        关卡进度与星级、手动备份档、成就、重新开始
├── 游戏本体      回合制指挥：选中/框选多选、下令移动、自动攻击
├── 兵种          步兵/炮兵 + 骑兵/散兵/掷弹兵（3 个新兵种，文字占位）
├── 敌方 AI       stationary / breakthrough / cluster（集中突破/聚团/站桩）
├── 关卡          主线 1~6 + 隐藏 7，每关难度与敌方策略不同
├── 战斗辅助      攻击范围圈、常驻行动箭头、左右信息面板（己方/敌方）
├── 存档          a.save 活动档 + 手动备份 1~3（可覆盖/载入）
├── 叙事          战前情报、剧情对话、三种结局页
└── 成就          胜利 / 惨痛失败 / 法兰西帝国 / 失败乃成功之母
```

页面与脚本详见 `AGENTS.md` 的“项目结构”。

## 4. 技术细节

- **开发平台**：Microsoft Edge + VSCode；无需构建工具。
- **运行平台**：纯静态页。直接双击 `index.html`，或在目录下运行本地静态服务器（如 `python -m http.server 8000`）后访问 `http://localhost:8000/index.html`。建议使用 Chrome / Edge 等现代浏览器。
- **技术栈**：原生 HTML + CSS + JS；数据全部存 `localStorage`（`users`、`a.save:<用户名>`、`save1~3`、`achv:` 等），无后端、无框架、无外部依赖。
- **脚本约定**：游戏页固定加载顺序 `constants → pieces → arrow → dialog → account → save → main → ai → levels → gameN`。
- **关卡与 AI**：跨关卡设计信息集中在 `js/levels.js`（注册表），各关棋子配置留在各自 `gameN.js`，方便成员独立维护。

## 快捷玩法提示

1. 在 `index.html` 注册登录 → 主界面 → 第 1 关；
2. 左键框选部队、点空地下令（有蓝色常驻箭头）；点“查看敌人”可看红方剩余血量；
3. 第 1 关 ≤12 回合通关可解锁隐藏路线（第 6 关后挑战第 7 关）。
