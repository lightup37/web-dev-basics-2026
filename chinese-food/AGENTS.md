# 项目描述

将教材第6章（见 book.md）的综合实例补充完整，最后完成的网站应该是个整体。建议进行一定的内容和显示效果再设计。

整体性定义：至少完成3个菜系，每个菜系下至少3个代表菜肴。如果3个菜系中包含川菜，则可以使用原有页面，但需要将其补充完整。自行制作的页面个数（包括2级页面和3级页面不少于8个页面）。

此网站需要做成响应式，具体请参见教材9.5.2（注意教材中的响应式制作并不完整，需要自行设计开发补齐）。

评分标准：

合格（6-8）：所有链接正常工作，信息组织正确，内容完整，文件命名合理，技术运用合理，具有基本的响应式（在不同显示设置能正常显示）。

优秀（9-10）：满足合格标准，信息组织优秀，内容充实，设计有创新且美观，技术应用有一定创新。兼容性好，响应式设计能适应多种浏览器和显示设置。

# 额外要求

使用尽可能简单的 html+css 方案实现网站; css 代码需要尽可能简单, 且在关键的内容处添加注释, 并描述这些 css 内容用在何处, 为什么要这样设置.

使用尽可能简单的 css 方案解决问题; 网站主要采用卡片来构建.

如果有需要下载图片的情况, 从可信任的网站上直接下载, 不用请求我的许可.

不要探索上级目录。你只需要本目录里的信息。
