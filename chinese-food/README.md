# 中华美食网(课程综合实例)

将教材第6章"中华美食网站"综合实例(见 `book.md`)补充完整并重构为**卡片化、响应式**网站。
保留教材的站点骨架(固定顶部工具条 / 横幅 / 主导航 / 面包屑 / 深底页脚),
内容与视觉按"简单 HTML+CSS、卡片构建、现代再设计"的思路重做。

## 规模与整体性

- 菜系:川菜、鲁菜、粤菜、湘菜 4 个;每菜系 5 道代表菜(共 20 道)。
- 页面:共 **26 个 HTML**(首页 + 4 菜系二级页 + 20 菜品三级页 + 独家菜单),
  其中自制二级/三级页 24 个(要求 ≥8)。
- "联系我们"采用顶条/页脚的 **mailto: 直邮链接**(1120251902@bit.edu.cn),不再单独建页。
- 三级页按教材结构:左栏"去哪儿吃?"(2 家店)+"怎么做?"(原料/步骤/贴士),
  右栏介绍一种**中华烹饪工艺**(炒/爆/烧/焖/炖/煨/熘/炸/烤/煮/蒸 等)。
- 每个三级页配了真实感的图文与示例店铺信息;`example-book/` 保留教材原始残缺文件,仅供对照参考,不在站点中引用。

## 怎么查看

直接双击根目录 `index.html` 用浏览器打开即可(纯静态,无需服务器)。
建议用不同窗口宽度(桌面/平板/手机)检查响应式表现;搜索框支持"完全匹配"跳转,
例如输入:宫保鸡丁、川菜、独家菜单。

## 技术要点(简单方案)

- 仅 HTML + CSS + 少量原生 JS(搜索),未用任何框架与构建工具。
- CSS 按页级分层:`base.css` 存全站变量与骨架(每个页面先引入),
  `home/cuisine/dish/content.css` 只存各自结构,关键规则均带中文注释(作用+理由)。
- 卡片是主要构件:`.card` 统一样式,各页复用。
- 配色用 CSS 变量,`body.theme-chuan/lu/yue/xiang` 一键切换菜系主题色;
  主色 `#E8A94C` 等金色元素呼应教材设计。
- 响应式自行补齐(教材 9.5.2 不完整):`base.css` 末尾两档断点
  (≤900px 平板、≤640px 手机)+ 各页 `grid auto-fit` 自动换列,
  适配桌面/平板/手机不同宽度。
- 未建设的苏、浙、闽、徽四菜系只在首页"八大菜系一览"作文字介绍,不设死链,
  保证"所有链接都能正常工作"。

## 维护工具

- `tools/download_images.py`:经本机代理从 Wikimedia Commons 抓取/替换图片
  (文件映射见 `images/CREDITS.txt`)。
- `tools/verify_links.py`:遍历全站 HTML,检查内部链接与资源引用是否都有对应文件。
- `tools/audit.py`:HTML 标签配对、CSS 花括号配平、搜索词典路径检查。
